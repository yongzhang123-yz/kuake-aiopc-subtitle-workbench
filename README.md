# 字幕整理与检查工作台

检查字幕时间和长行，调整换行、替换文字，再带着清楚的字幕交付。

适用对象：OPC企业、独立创业者及小型业务团队。中文界面，原生HTML/CSS/JavaScript，MIT开源，无第三方前端依赖。

## 界面预览

![界面预览](preview.png)

## 功能

- UTF-8 SRT导入和格式校验
- 时间重叠、长行和阅读速度检查
- 保留时间轴的换行和文字替换
- SRT、纯文稿和检查报告下载

## 快速开始

**离线使用：** 下载完整仓库后双击 `index.html`，点击“载入示例”，再点击左侧主按钮。

**本地服务：** 在本文件夹运行（Python 3.9或更高版本）：

```bash
python3 server.py
```

打开 `http://127.0.0.1:8765`。端口占用时可用 `python3 server.py --port 8766`。服务只绑定本机。Windows可用 `py server.py`。

## 示例与使用流程

三条SRT字幕，刻意保留一处时间重叠和一条长行便于演示。

1. 载入示例，查看左侧资料。
2. 点击主按钮运行，查看右侧结果。
3. 按实际工作修改输入并重新生成；文档类结果也可点“编辑结果”。
4. 使用导出、专用下载或打印保存成果。页面刷新不保留资料，关闭前请导出。

## 费用与联网

所有业务功能都在浏览器本地完成，不需要模型密钥或联网，不收取调用费用。

## 功能边界

重叠只提示，不擅自改时间；不做语音识别、翻译或专业字幕格式转换。

模板结果、规则整理与AI结果在界面明确区分；业务事实和客户承诺请人工核对。

## 文件结构

- `index.html`：独立入口
- `app.js`：本工具业务逻辑与示例
- `core.js` / `style.css`：页面、交互及通用导出
- `lib.js`：计算、字幕、剧情或ZIP辅助函数
- `server.py`：可选本地静态服务和AI代理
- `examples/`：示例说明
- `LICENSE`：MIT许可证
